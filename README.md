# 🕸️ 可视化拓扑构建/分析工具

一个**纯前端、零依赖**的图（Graph）可视化与拓扑分析工具。所有功能在浏览器本地完成，无需服务器，数据不会上传。

## 🔗 在线使用

直接在浏览器打开即可使用（GitHub Pages 托管）：

```
https://ghk2501.github.io/graph-tool/
```

也可以下载**单文件版** `graph-tool-single.html`，双击即可在浏览器本地打开，无需安装任何依赖、无需服务器，功能与在线版完全一致。

## ✨ 功能特性

### 图编辑
- **节点**：圆形 / 方形 / 三角形 / 五边形 / 六边形，支持自定义颜色、大小，可拖拽移动
- **连线**：单向直线 `-`、单向弧线 `~`、双向直线 `=`、双向弧线 `~~`（4 种类型）
- **弧线控制点**：拖拽二次贝塞尔控制点自定义弯曲形状
- **右键菜单**：节点与边的增删改（颜色、形状、方向、直线/弧线互转）
- **形状感知箭头**：端点按节点实际形状/大小精确计算，箭头始终紧贴节点边缘（三角形/五边形等同样准确）
- **边缘扇形分流**：同一节点多条入边沿节点边缘按弧距错开，箭头不重叠、不飞出节点
- **🧲 自动布局**：力导向布局一键整理当前画布，节点均匀铺开、减少边交叉（弧线弧度自动保持）

### 🎲 随机生成拓扑
- **数量可控**：直接指定节点数/连线数，或给定范围后完全随机
- **结构预设**：完全随机 / ⭕ 环形 / ⭐ 星形 / 🌲 树形（连通无环）/ ☸️ 轮辐 / 🕸️ 网格
- **样式随机**：节点形状、颜色、大小与连线类型（单/双向 × 直线/弧线）可独立开关随机

### 拓扑分析
| 功能 | 说明 |
|------|------|
| **环路分析** | 查找所有简单环路，自动去重排序，点击高亮显示 |
| **两点路径分析** | 查询两点间所有简单路径，并单独给出最短路径 |
| **几何交点统计** | 直线-直线 / 直线-弧线 / 弧线-弧线交叉点计数 |

### 导入导出
- 文本格式：`0-1，0~1，0=2，1~~3`
- 支持单向 `-`/`~` 与双向 `=`/`~~`，兼容中英文逗号与换行

## 🚀 本地运行

无需安装任何依赖，下载 `graph-tool-single.html` 直接双击打开即可；或运行：

```bash
# Python
python -m http.server 8000

# Node.js
npx serve .
```

然后访问 `http://localhost:8000`。

## 🛠️ 技术栈

- 原生 HTML + CSS + JavaScript（ES6），零依赖、零构建
- SVG 矢量渲染，二次贝塞尔曲线
- 算法：DFS（环路/路径搜索）、旋转归一化去重、叉积几何求交、Fruchterman-Reingold 力导向布局、多边形边界解析求交
